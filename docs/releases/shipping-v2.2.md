ChopTorch 2.2

Use a double-chop phone motion to toggle the flashlight while monitoring is enabled.

- Monitoring is user-started and runs with a foreground notification.
- Requires a camera flash, accelerometer, and gyroscope.
- Sensor delivery and background behavior vary by device and Android version.

Install the APK from this release. Android may ask you to allow installs from the app used to download it.
