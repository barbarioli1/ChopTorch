ChopTorch: Shake Flashlight

An Android flashlight controlled by a double-chop motion, with gesture recognition processed on the device.

Privacy policy (English) Política de privacidade Source code

About

ChopTorch is an independent Android project. It uses the accelerometer and gyroscope to recognize a double-chop gesture and control the device flashlight. Motion processing and the bundled model run locally.

Background monitoring is user-started, uses an Android foreground service, and can be stopped from its persistent notification. Android or device battery policies may interrupt it.

This project is not affiliated with Motorola.

Privacy and support

The production app does not transmit motion readings or usage data to ChopTorch servers. Read the full privacy policy for permissions, local storage, and deletion details.
